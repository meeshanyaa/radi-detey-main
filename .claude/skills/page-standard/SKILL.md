# Сборка страницы по стандарту

Навык — это процедура и проверка каждого шага. Стандарт лежит в STANDARD.md, тексты в content.md, журнал в JOURNAL.md.

## Порядок

1. Прочитать STANDARD.md целиком, включая раздел 11 «Правила, добавленные по ходу».
   Проверка: для задачи назван компонент из раздела 5. Если подходящего нет, новый компонент сначала описывается в стандарте, и только потом верстается.
2. Взять тексты только из раздела 8 стандарта и content.md.
   Проверка: каждый факт на странице есть в одном из этих файлов. Недостающее помечается [__] и выносится в вопрос, а не придумывается.
3. Собрать или изменить один компонент за итерацию: сначала в components.html со всеми состояниями, потом на странице.
   Проверка: цвета только через переменные из `:root`, кегли и отступы из разделов 2 и 3.
4. Пройти шесть проверок раздела 9 стандарта.
   Проверка: ширины 320, 360, 390, 768, 1024 и 1440 px без прокрутки вбок, обход клавишей Tab с видимым кольцом фокуса, консоль без ошибок, тексты сверены, форма проверена во всех сочетаниях полей.
5. Записать итерацию в JOURNAL.md: запрос дословно, что получено, ошибка, как найдена, как исправлена, правило.
   Проверка: если ошибка может повториться, правило добавлено в раздел 11 стандарта с номером итерации.
6. Оформить итерацию отдельным коммитом с номером итерации в сообщении (раздел 7).
7. Только после шагов 4–6 сказать «готово» и перечислить, что проверено.

## Чего не делать

- Не подключать шрифты, библиотеки и счётчики с чужих доменов: шрифт лежит в fonts/.
- Не вписывать настоящие контакты, ключи и токены. На странице условные контакты из раздела 8.
- Не ставить заранее галочку согласия и не заменять подпись поля плейсхолдером.
